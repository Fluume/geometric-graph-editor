# Geometric Graph Editor

Made with ❤️ by Tilio Ferazzi and Yann "Fluume" Quentel.

## Overview

An open-source geometric graph editor developed as part of a school project. This tool allows users to create, visualize, and manipulate geometric graphs with various predefined graph constructions.

## Features

- Add and remove vertices interactively.
- Support for multiple geometric graph types:
  - Unit Disk Graph
  - [Gabriel Graph](https://fr.wikipedia.org/wiki/Graphe_de_Gabriel)
  - [Nearest Neighbor Graph](https://en.wikipedia.org/wiki/Nearest_neighbor_graph)
  - Integer Graph
  - k closest-neighbors Graph
  - [Minimum Spanning Tree](https://en.wikipedia.org/wiki/Minimum_spanning_tree)
  - [Relative neighborhood graph](https://en.wikipedia.org/wiki/Relative_neighborhood_graph)
  - [Triangulation of Delaunay](https://fr.wikipedia.org/wiki/Triangulation_de_Delaunay)
  - [Urquhart graph](https://en.wikipedia.org/wiki/Urquhart_graph)
  - [Theta Graph](https://en.wikipedia.org/wiki/Theta_graph)
  - [Yao Graph](https://en.wikipedia.org/wiki/Yao_graph)
  - Yao 4_Linfty
  - TD-Delaunay graph
  - L1-Delaunay graph
  - Demi-Theta6 Graph
- Drag-and-drop functionality for moving vertices.
- Save and load graphs with customizable file formats.
- Real-time graph updates on vertex modifications.
